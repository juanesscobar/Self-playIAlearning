# AlphaZero-Style Medical Self-Play Framework 🧠⚕️

**AlphaZero-inspired self-play and self-improvement framework applied to sequential medical decision-making (research & educational prototype).**

Este repositorio implementa un enfoque tipo **AlphaZero** (Self-Play + MCTS + Neural Networks) adaptado a problemas médicos secuenciales, usando entornos simulados y datos sintéticos, con el objetivo de:

- Explorar **razonamiento clínico secuencial**
- Investigar **aprendizaje por auto-mejora (self-improvement)**
- Servir como **MVP / portfolio técnico** para roles en AI, RL y Applied ML
- Sentar bases para una **startup de IA en salud** (con énfasis en seguridad y cumplimiento legal)

> ⚠️ **Aviso importante**:  
> Este proyecto **NO es un sistema médico real** y **NO debe usarse para diagnóstico o tratamiento clínico**.  
> Todo el código trabaja con **entornos simulados y datos sintéticos**.
